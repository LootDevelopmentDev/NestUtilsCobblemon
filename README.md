## NestUtilsCobblemon
___
### About Project
  This project was made as a utility for a Minecraft mod-pack based on the mod Cobblemon version 1.21.1 for the Fabric mod loader, which adds items and mechanics used for progression and crafting within the modpack's quest system. These items include:
  - New crop "Kings Leaf", from Pokemon Legends ZA, added to the game via JAVA and to it's own blocks loot table via JSON
  - New seed type for "Kings Leaf" crop added to the game via JAVA and to it's own blocks loot table via JSON
  - Block model for "Kings Leaf" made using BlockBench, a 3D modeling software for Minecraft mod makers
  - Block growth animation made using JSON to define the hitbox and textures at each stage
  - New Block class added for the crop, adding custom hitboxes for each stage of growth
  - Added datagen to automatically generate JSON files for items made using fabric API

### Goal
  The goal of this project was to understand both modpack developement and mod devlopment in order to eventually ship a fully build package for others to play, using Minecraft as the basis for this idea. This mod is a utility that adds features that accomplish the goal of creating a cohesive experience using other mods as a foundation.
